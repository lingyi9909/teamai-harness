# 内网知识目录

本文件是公共目录说明。实际内容只在内网编写，不回传到 `lingyi9909/teamai-harness`。

需要第一份资料时再创建对应目录，无需提前建立大量空目录：

```text
docs/codea-knowledge/
├── README.md
├── common/                   # 公共组件说明、术语、公共规则
└── projects/                 # 项目介绍及权威来源引用
```

项目专属正式业务规则保留在各业务仓库，团队仓只记录引用。若已有同类目录，沿用原目录即可，不迁移、不维护第二份规则。

从 `templates/codea-harness/` 选择模板创建新文件，然后填写来源、负责人、适用范围、版本和状态。模板/未填写资料始终是草稿，不能直接参与业务判定。机器读取与证据认证需等待 1.7 核心实现并联调，复制 Markdown 不会自动启用这些能力。

知识正文避免凭据、会话、原始日志和运行报告。保密范围不同的资料保持原受限仓库权限；目录分组不能代替访问控制。
