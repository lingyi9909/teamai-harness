# 项目资料模板（DRAFT）

本文件仅记录介绍与引用，不复制业务规则正文，不是 Runtime 配置。

| 字段 | 待填写内容 |
|---|---|
| 项目 ID / 名称 | 稳定身份及业务名称 |
| 负责人 | 内网负责团队 |
| 业务仓库 | 内网仓库身份；不填写本机凭据 |
| 项目范围 | 核心职责和不负责的业务 |
| 技术入口 | 当前模块和入口线索，以实际代码复核 |
| 正式业务规则 | 业务仓库内权威文档相对路径、适用版本 |
| 必查规则 | 明确哪些规则对于哪些 Review 目标必需 |
| 公共知识引用 | 团队资料根内的路径、文档 ID、适用版本 |
| 状态 / 更新时间 | DRAFT，待项目负责人确认 |

不在此填写机器绝对路径或猜测 TeamAI 缓存位置。1.7 核心知识绑定实现后，由项目本机配置关联已准备好的资料根；未实现前此文件仅用于资料整理。
