# 业务规则模板（DRAFT，不生效）

本文件仅为填写模板，非实际公司规则，非自动可执行的 schema。

| 字段 | 待填写内容 |
|---|---|
| ruleId | 项目内稳定且唯一的编号 |
| 状态 | DRAFT；实际生效需引用团队评审记录 |
| 项目及适用范围 | 项目 ID、模块、入口/操作、触发条件 |
| 业务要求 | 可判断的前置条件、允许行为、禁止行为及结果 |
| 例外 | 明确例外和对应依据；没有则注明无 |
| 权威来源 | 业务仓库文档相对路径、需求/评审来源 |
| 版本及生效条件 | 规则版本、适用业务版本/生效日期 |
| 负责人 | 内网负责人或负责团队 |
| 最后确认 | 日期、评审记录及确认人 |

## Review 如何判断

填写应检查的行为以及需要的源码依据。代码位置只是线索，Reviewer 必须复核当前源码，不能凭文档位置直接认定缺陷。

## 正例与反例

填一个允许场景和一个违反场景，并说明关键条件。不要把尚未确认的推测写成强制要求。
