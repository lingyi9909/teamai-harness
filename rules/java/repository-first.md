# Repository first

Before changing Java code, read the repository's local instructions and inspect the owning module's build file, nearby code, nearby tests, package structure, and existing conventions. Local project evidence overrides generic recommendations in this harness.

Do not assume Spring, JPA, MyBatis, Lombok, MapStruct, Maven, Gradle, Java version, test libraries, logging stack, or architecture style. Infer them from checked-in evidence. Make the smallest change consistent with the existing boundaries and avoid opportunistic rewrites outside the requested scope.
